Trace-driven debugging — a failing question, diagnosable from its spans

Author: Chia-Jung Wang (@chiajung-wang) Issue: #56 Branch: step-8/issue-56-trace-debugging → main

1 Overview

Open a failing question's trace and see, per span, exactly what each stage did — with no raw PII anywhere. That is Step 8's "done when", and this issue proves it.

eval.prove_step8 drives a retry-exhausted failing question through the import-shared run_pipeline — the same loop the harness and demo run — while an in-process TraceRecorder captures the per-stage spans exactly as Langfuse would (start_as_current_observation with automatic nesting; update carrying each stage's safe output). It is offline and deterministic: a fake LLM client, no live model, no Langfuse keys (the defer-API-key discipline). The live trace is the same shape once a key is supplied.

The captured trace is rendered to a self-contained HTML artifact for the blog (docs/plans/step-8/example-trace.html) and asserted to carry no raw PII value — and RESULTS.md records the Step-8 operational milestone with its config and commit.

2 What the failing trace shows

Every facet the "done when" calls for is present and asserted — and the recorder is contract-parity with the real Langfuse seam (same metadata/output/level/ usage_details fields _span_update writes).

spanwhat it tells the debugger
retrievewhich tables were selected (['orders','users']) + the retrieval mode
generate ×2the candidate SQL — one generation span per attempt, with token usage
guardthe verdict (decision=allow): the SQL parsed and was in scope
execute ×2the execution error as the exception class (OperationalError), span flagged red
correctthe failure fed back; the not-found error triggered a loop-aware re-retrieve
redactthe presented exit — nothing to present on a failed run (presented=False)

The budget is spent after the second errored attempt → the harness classifies retry_exhausted. The classifier stays in the harness (the script imports classify_terminal_state, never reimplements it); the recorder only records.
