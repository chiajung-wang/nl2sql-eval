Result-set majority voting — the comparator, repurposed as a selector

Author: Chia-Jung Wang (@chiajung-wang) Issue: #142 Branch: step-12/issue-142-majority-voting → main Source: Shkapenyuk et al., arXiv:2505.19988v2 §4 (AT&T #1 BIRD)

1 Overview

Generate several candidates; pick the one the most executions agree on. The paper's submission votes on result-sets — and we already own exactly that equivalence: our comparator (eval/compare.py) is the result-set equivalence a vote needs, BIRD set-semantics included. So voting is the proven comparator applied to candidate selection instead of gold scoring — we reuse the core, we don't rebuild it (no new equivalence, no string-match, no LLM judge).

2 Voting is the comparator, pointed sideways

k candidates→ execute each→ group by compare(a,b,"SELECT 1").correct→ largest class wins→ earliest-index tiebreak 
# the comparator decides equivalence — set-semantics, float tolerance, NULLs —
# the same rules that score against gold. "SELECT 1" is an order-insignificant
# sentinel (no gold exists at selection time) → "convert results to sets".
candidates: [ {1}, {2}, {1} ]   # 0 and 2 agree
  → classes {0,2} (size 2), {1} (size 1)  → select 0  (agreement 2/3)

A size tie or no-majority is broken deterministically by earliest candidate index — the paper picks randomly; a reproducible tiebreak is required by §9. Errored candidates are excluded; if all errored, the first is returned so a run is never lost.

4 Diversity + the honest null

Candidate diversity (eval/candidate_diversity.py): the paper's schema-field-order randomization — a seeded, deterministic permutation of each table's columns (seed 0 = identity). The second lever, LLM seed variation, only bites with a stochastic model, so it rides the deferred live path.

Per Step 5's lesson, the agreement_distribution (unanimous / majority / no-majority) is the real diagnostic: a strong generator whose candidates agree makes the vote a no-op (+0.000) — an honest null is the expected, acceptable outcome. The finding is where voting beats attempt-1 (likely the weaker generators, as the self-correction twin found).
