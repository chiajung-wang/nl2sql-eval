1 Overview

The Step-4 Definition of Done: complete the named-deliverable red-team fixture and state the measured safety claim — "caught 100% of red-team queries."

A safety feature is only as good as the test that proves it. This slice finishes that test. It adds the sharpest attack class — prompt injection: natural-language prompts that try to talk the model into dangerous SQL. The defense is not an LLM judge or a regex on the question; it is the same deterministic sqlglot-AST gate. Even if the model is manipulated into emitting DROP TABLE or an exfiltration ATTACH, the gate rejects the payload before it reaches a database.

Each NL attack is paired with the payload it induces and replayed through the real generate → guard path via an injected client (no network). The faked part is only the model's response; the gate under test is real. The benign control proves the gate judges the SQL, not the prompt's tone.

4 Honesty of the claim

  • Deterministic, reproducible — the catch rate is over fixed SQL payloads; no model in the loop for the number. RESULTS.md attributes it to the gate, not a model run.
  • Not an LLM judge, not a regex — injection mitigation is the same AST gate (CLAUDE.md §4, §7).
  • Catch-rate math is sound — the denominator is exactly the reject-labeled cases; a benign case can never be counted as "caught", and a reject case must actually be rejected.
  • Scope honored — table-scope enforcement stays deferred to Step 6 (needs per-db metadata).
