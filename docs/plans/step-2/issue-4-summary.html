2 The reference: BIRD's evaluator

The official BIRD evaluator (AlibabaResearch/DAMO-ConvAI → bird/llm/src/evaluation.py) decides correctness with a single line over cursor.fetchall():

if set(predicted_res) == set(ground_truth_res): res = 1

That one set() makes BIRD simultaneously order-insensitive — always (even with a gold ORDER BY), duplicate-collapsing (multiplicity is invisible), and exact on values (no float tolerance). Those three properties are precisely where our default scorer chooses to differ.

4 The set rule & BIRD_RULES

The set rule — BIRD's primitive

  • De-duplicates and order-normalizes rows in one step — exactly set(fetchall()).
  • Re-sorts by _row_sort_key for a deterministic canonical form; never reads the gold SQL, so it ignores ORDER BY like BIRD.
  • Its absence from DEFAULT_RULES is what makes our scorer multiset and order-aware.

Two named rule sets

  • DEFAULT_RULES = column_position · null_sentinel · float_tolerance · order_insensitive · exact — the refinement.
  • BIRD_RULES = column_position · set · exact — opt-in, reproduces BIRD's verdict exactly.
  • The gap between the two pass-rates is exactly the set of verdicts BIRD's set() masks — worth reporting, not hiding.
