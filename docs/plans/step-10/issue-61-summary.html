3 The thesis in one line

Build the thing that can tell you the truth before you build the thing you hope is true. A proven comparator before a benchmark number. A red-team fixture before a guardrail claim. A twin metric that can report self-correction is worth zero. A recall metric that sees the failure accuracy can't. A harness that proves a framework swap changed nothing. A trace debuggable without leaking PII. A CI job that catches a prompt regression before it ships. The NL-to-SQL agent is the workload; the measurement apparatus is the product.
